# Indira International School - Project Documentation

Welcome to the documentation for the Indira International School website redesign. 
These documents outline the product strategy, content, design, and technical architecture, and act as a guide for deployment and maintenance.

## Index of Documents

1. [**01-product-brief.md**](./01-product-brief.md): Outlines the primary goals, target parent personas, and the MVP scope (what is included and excluded).
2. [**02-sitemap-and-content-plan.md**](./02-sitemap-and-content-plan.md): Defines the site structure, page-by-page content requirements, and a checklist of assets the school needs to provide.
3. [**03-design-system.md**](./03-design-system.md): Establishes the visual theme, color palette, typography, and component styling rules to ensure a professional, non-generic look.
4. [**04-wireframes.md**](./04-wireframes.md): Text-based structural layouts for the Home, Admissions, and Contact pages across mobile and desktop.
5. [**05-tech-architecture.md**](./05-tech-architecture.md): Recommends the hosting setup, tech stack (Static Site), form handling method, and estimates annual running costs (~₹800 INR).
6. [**06-seo-and-launch-checklist.md**](./06-seo-and-launch-checklist.md): A comprehensive checklist covering local SEO, performance targets (Lighthouse 90+), accessibility, and pre-launch testing.
7. [**08-deployment-guide.md**](./08-deployment-guide.md): Instructions on how to deploy the site for free on Cloudflare Pages and how staff can edit the content.
